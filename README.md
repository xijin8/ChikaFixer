# 汐瑾 CHIKA 修复启动器

**免费分享的 CHIKA 登录修复工具。仅发布可执行软件和使用说明，不发布项目源码。**

用于尝试解决 CHIKA 不弹登录界面、无法登录的问题。当前只支持已验证的 **CHIKA 4.6.1** 文件，其他文件版本会提示并停止操作。

## 下载与准备

从 [GitHub Releases 下载软件包与校验值](https://github.com/xijin8/ChikaFixer/releases/tag/v1.0.1)，下载附件 `Xijin_CHIKA_Fix_Launcher_v1.0.1.zip`，完整解压后使用。请保留同目录的 `XijinChikaLauncher.exe` 和 `_internal`，不要单独拿走一个 EXE。

需要准备的只有三个：

- 汐瑾 CHIKA 修复启动器完整软件目录
- 雷小伊登录器
- CHIKA 登录器完整目录

本软件包不包含雷小伊和 CHIKA 登录器本体。

## 使用方法

1. 打开“汐瑾chika修复启动器.exe”，按提示确认管理员授权。
2. 在软件中选择自己电脑上的雷小伊登录器和 CHIKA 登录器 EXE。
3. 点击左下角“自动抓取 DUID”，软件会自动打开雷小伊。正常输入自己的账号密码登录；如果没有弹出登录框，先清缓存，直接刷新，再登录。
4. 等修复器提示 DUID 已保存后，直接关闭雷小伊；不关也行，此时已经获得 DUID。
5. 点击右下角“登录 CHIKA”，自动打开 CHIKA 并复用账号历史。正常情况下可以通过已有账号继续登录；如没有自动打开登录界面，请手动点击“开始”。如官方页面仍要求密码或验证码，请自行完成。

之后每次通常只需：打开修复器 → 点击“登录 CHIKA”。换账号、DUID 失效或账号历史异常时，重新获取一次。

使用期间保留修复器运行；退出时先关闭 CHIKA，再关闭修复器。运行时会临时调整 CHIKA 本地页面和 IE 设置，退出后恢复，并会清理临时网页缓存。

## 为什么做这个工具

9 月 12 日，我在雷小伊群里分享过一份 Python 脚本，帮助大家解决 CHIKA 不弹登录界面、无法登录的问题。后来看到有人把脚本整理成自己的解决方案发布，也发现不少朋友不会运行 Python 脚本。

不少老玩家和回归玩家还是比较喜欢 CHIKA 登录器。最近重新尝试时，我发现旧脚本已经不好用了，于是又做了修复，并打包成能直接打开的软件，免费分享给需要的朋友，希望大家少折腾一些。

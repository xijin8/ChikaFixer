# 汐瑾 CHIKA 修复启动器 / Xijin CHIKA Fix Launcher

只要电脑上已有 **雷小伊登录器**，就能修复 CHIKA 登录器用不了的问题（点“开始”不弹登录框、无法识图等）。

- 不修改 CHIKA 本体文件，不改你的账号密码
- 只需获取一次 DUID，之后打开软件点一下就能直接登录 CHIKA
- 全程本地运行，不上传任何数据

## 下载

在本仓库的压缩包 `汐瑾chika修复启动器_v1.0.zip` 中下载，解压后使用。
仓库内不提供源码，只提供可直接运行的软件和使用说明。

## 使用步骤

1. **打开软件**
   解压整个压缩包，双击 `汐瑾chika修复启动器.exe`，允许管理员授权（UAC）。
   必须整个文件夹一起使用，不能只留 exe——需要和 `XijinChikaLauncher.exe`、`_internal` 同目录。

2. **填入路径**
   把自己电脑上的雷小伊登录器和 CHIKA 登录器位置填进软件（点“浏览”选择 exe）。
   路径会自动记住。

3. **获取 DUID**
   点左下角“获取 DUID”，软件会自动打开雷小伊。正常输入账号密码登录。
   如果没有弹出登录框：清缓存 → 直接刷新 → 再登录。

4. **关闭雷小伊**
   拿到 DUID 后直接关闭雷小伊即可（不关也行，此时 DUID 已经获取完成）。

5. **打开 CHIKA**
   点右下角“打开 CHIKA”，软件会自动打开 CHIKA。不用输入账号密码，直接登录。

之后每次使用：打开软件 → 直接点“打开 CHIKA”。换账号或 DUID 失效时，重新做第 3、4 步。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 点“开始”不弹登录框 | 按第 3 步先清缓存再刷新页面重新登录 |
| 提示找不到程序 | 重新选择雷小伊 / CHIKA 的可执行文件路径 |
| 打开无反应或提示权限不足 | 右键 → 以管理员身份运行 |
| 安全软件拦截 | 将整个文件夹加入信任后再运行 |
| CHIKA 版本不符 | 本工具只支持已验证的 CHIKA 版本，会提示并停止操作 |

## 说明

- 本工具**不包含**雷小伊登录器和 CHIKA 登录器本体，请自行准备。
- 不代填账号密码、不操作验证码，登录仍由你自己完成。
- DUID 保存在本机 `CHIKA历史.duid`，相当于登录凭证，请不要外发。
